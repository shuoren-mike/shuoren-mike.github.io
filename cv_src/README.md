# One-page CV sources

LaTeX sources for `../cv_en.pdf` and `../cv_zh.pdf`.

The Chinese version uses Noto Serif CJK SC / Noto Sans CJK SC so it builds on Linux.
Figures and the portrait are referenced as `../materials/...`; place a `materials/`
directory next to this one, run `make`, then copy the PDFs up one level.
